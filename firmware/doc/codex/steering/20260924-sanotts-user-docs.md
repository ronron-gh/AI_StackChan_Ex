# SanoTTS-jp ユーザー向けドキュメント

## 目的

日本語版の基本利用ガイドに SanoTTS-jp の対応状況を追加し、利用者がライブラリ、モデル、辞書を自分で用意してビルドできるように、独立した設定手順を作成する。

## 対象範囲

- 日本語版 `doc/basic_usage.md` の TTS 一覧、デバイス対応表、YAML 設定例
- 新規の日本語版 SanoTTS-jp 設定ページ
- SanoTTS-jpは日本語用TTSのため、英語版ドキュメントは更新しない

## 主な変更ファイル

- `../doc/basic_usage.md`
- `../doc/tts_sanotts.md`（新規）
- `firmware/doc/codex/steering/20260924-sanotts-user-docs.md`

## 実装方針

- `basic_usage.md` の AquesTalk の記載に倣い、SanoTTS-jp がローカルで日本語音声を合成できること、CoreS3 のみ対応すること、追加ファイルが必要なことを簡潔に示し、詳細ページへリンクする。
- YAML 例の `tts.type` に SanoTTS-jp の値 `5` を追加し、SanoTTS-jp では `model` と `voice` の設定を使用しないことを示す。
- 詳細ページ `tts_sanotts.md` には、検証用リポジトリ `SanoTTS_Arduino_CoreS3` から必要ファイルを取得する手順、モデルと辞書の配置、辞書取得スクリプトの実行、SanoTTS用 PlatformIO 環境でのビルド、YAML 設定を順番に記載する。
- ライブラリ、モデル、辞書は本リポジトリに含まれず、各利用者が配布元のライセンスを確認して取得することを明記する。
- 標準の蓄積再生と、ビルドオプションで切り替えられるストリーミング再生・再生速度について、利用者が設定判断できる範囲で説明する。
- 既存の開発者向けメモ `firmware/doc/sanotts.md` と実際の `platformio.ini` を根拠にし、ユーザー向け手順と実装の設定値を一致させる。

## 設計上の注意点

- 対象ボードと PlatformIO 環境名は実装済みの構成に限定し、未検証の組み合わせを案内しない。
- 外部ファイルの名称、配置先、コマンドは検証用リポジトリの最新 README と本リポジトリのビルドスクリプトに合わせる。
- ライセンス条件を独自に要約しすぎず、配布元の文書を確認するよう案内する。
- AquesTalk の既存説明と同程度の導線を保ちつつ、SanoTTS-jp 固有の準備手順は詳細ページに集約する。

## 確認方法

- Markdown の表、見出し、相対リンクが正しく表示できることを確認する。
- 記載したファイル名、配置先、環境名、ビルドオプション、`tts.type` が現在の実装と一致することを静的確認する。
- 日本語版以外に差分が生じていないことを確認する。
