# SanoTTS の再生方式

`m5stack-cores3-sanotts` では、句読点・改行・入力上限で分けた区間ごとに音声を合成し、区間全体の PCM を PSRAM に蓄積してから再生します。区間内の推論が再生速度より遅くても音は途切れませんが、再生開始前と区間間に合成待ちが生じます。

`platformio.ini` の `[sanotts-cores3]` から `-DSANOTTS_BUFFERED_PLAYBACK` を外すと、従来の先読み・循環バッファによるストリーミング再生に戻ります。切り替え後は再ビルドしてください。

`SANOTTS_PLAYBACK_SAMPLE_RATE` は再生速度を調整するビルドオプションです。SanoTTS の生成レートは 22,050 Hz ですが、標準の SanoTTS 環境では 20,000 Hz として再生し、話速を約9%落としています。値を小さくするとさらに遅くなり、同時に声も低くなります。このオプションを指定しない場合は 22,050 Hz で再生します。

蓄積バッファは 22,050 Hz、16-bit mono の PCM で、最大30秒分（約1.26 MiB）を区間ごとに PSRAM に確保します。確保できなければその発話は失敗としてログに記録します。推論 arena は別に176 KiB必要です。両方式とも SanoTTS-jp のライブラリ、モデル、辞書を別途配置する必要があります。配置手順は検証用リポジトリ `SanoTTS_Arduino_CoreS3` の README を参照してください。
