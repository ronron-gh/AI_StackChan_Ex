# SanoTTS の再生方式

`m5stack-cores3-sanotts` では、句読点・改行・入力上限で分けた区間ごとに音声を合成し、区間全体の PCM を PSRAM に蓄積してから再生します。最初の区間を再生している間に次の区間を合成し、M5Unified の再生キューへ追加します。次区間の合成が現在区間の再生中に終われば、区間間の合成待ちは発生しません。リップシンク用の音量は生成時ではなく再生位置に合わせて更新します。

`platformio.ini` の `[sanotts-cores3]` から `-DSANOTTS_BUFFERED_PLAYBACK` を外すと、従来の先読み・循環バッファによるストリーミング再生に戻ります。切り替え後は再ビルドしてください。

`SANOTTS_PLAYBACK_SAMPLE_RATE` は再生速度を調整するビルドオプションです。SanoTTS の生成レートは 22,050 Hz ですが、標準の SanoTTS 環境では 20,000 Hz として再生し、話速を約9%落としています。値を小さくするとさらに遅くなり、同時に声も低くなります。このオプションを指定しない場合は 22,050 Hz で再生します。

蓄積バッファは 22,050 Hz、16-bit mono の PCM で、1区間あたり最大30秒分（約1.26 MiB）を PSRAM に確保します。先行生成時は最大2区間分（約2.52 MiB）に加えて、小さな音量エンベロープを保持します。次区間用の領域を確保できない場合は現在区間の再生完了後に古いバッファを解放し、直列生成で再試行します。最初の区間も確保できない場合は発話を失敗としてログに記録します。推論 arena は別に176 KiB必要です。両方式とも SanoTTS-jp のライブラリ、モデル、辞書を別途配置する必要があります。配置手順は検証用リポジトリ `SanoTTS_Arduino_CoreS3` の README を参照してください。
